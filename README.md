# KAZaircompressor

Сайт-каталог ТОО KAZaircompressor на React / Next.js. Тексты и изображения перенесены с [kazaircomp.kz](https://kazaircomp.kz/), визуальный стиль — как у [nur-tim](https://github.com/kindxxxx/nur-tim/).

## Запуск

```
npm install
npm run dev
```

Откройте http://localhost:3000.

Картинки лежат локально в `public/images/`. Для заявок в Telegram укажите в `.env.local`:

```
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```
